Topologi
Tiga router terhubung point-to-point membentuk backbone OSPF, masing-masing menurunkan satu LAN ke switch dan dua PC client. DHCP Server berada di LAN terpisah yang hanya terhubung ke R0.

// CATATAN PENTING
Kenapa ip helper-address?
DHCP RELAY

ip helper-address adalah bagian paling penting dari lab ini — perintah ini memungkinkan satu DHCP Server melayani banyak LAN yang berada di jaringan berbeda, tanpa perlu memasang DHCP server terpisah di setiap LAN.

Contoh di Router1: pada interface gigabitEthernet 0/0 ditambahkan ip helper-address 172.16.10.2. Artinya, setiap kali ada broadcast request DHCP dari LAN 192.168.20.0/24, router akan meneruskan request tersebut sebagai unicast ke DHCP Server di 172.16.10.2.

Hasil akhirnya: cukup satu DHCP Server terpusat di belakang R0 untuk melayani LAN10, LAN20, dan LAN30 sekaligus — jalur PC0 → Switch → R0 → R1 → R2 → Switch → PC5 terbukti berjalan saat pengujian ping end-to-end.
