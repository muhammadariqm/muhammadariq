02 — Konsep Utama

Alur Sistem

USER │ ├── Register / Login ├── Melihat saldo ├── Request Top Up │ ▼ ADMIN │ ├── Review Request ├── Approve → Saldo bertambah └── Reject → Status rejected │ ▼ USER MEMAINKAN SLOT │ ├── Bet → Spin → Menang / Kalah │ ▼ TRANSACTION + GAME HISTORY

Inti Desain

  • Admin mengontrol konfigurasi mesin global (probabilitas & payout)
  • User hanya bermain dengan saldo virtual
  • Hasil spin ditentukan server-side RNG
  • Setiap perubahan saldo & permainan tercatat di transaction / history
03 — Role Sistem

User & Admin

👤

User

Dashboard, Wallet, Request Top Up, Slot Machine, Game History, Transaction History. Tidak bisa ubah saldo, payout, atau konfigurasi mesin.

🛡️

Admin

Overview, User Management, Top Up Approval, Machine Config, Game History, Transaction History, Statistics, System Settings.

Authentication

Register → Create User → Create Wallet (balance = 0). Role disimpan di users.role (user / admin).

04 — Wallet & Top Up

Wallet System

Setiap user punya satu wallet. Saldo hanya berubah lewat operasi server yang valid.

Jenis Perubahan Saldo

TypeContohKeterangan
TOPUP+100.000Admin approve top-up
BET−10.000User menempatkan taruhan
WIN+50.000Payout kemenangan
REFUND+10.000Pengembalian (jika perlu)

Top Up Flow

USER → Request Top Up (status: PENDING) │ ▼ ADMIN → Review │ ├── APPROVE → Wallet +amount · Transaction TOPUP · status=approved └── REJECT → status=rejected · saldo tidak berubah
Keamanan saldo: Semua operasi memakai DB transaction — BEGIN → Lock Wallet → Check → Deduct/Add → Create Transaction → Create Game Session → COMMIT. Error → ROLLBACK.
05 — Slot Machine

Classic Slot Engine

Game pertama: Classic Slot Machine 3 reel. Simbol memakai asset PNG/WebP (bukan emoji).

Simbol & Payout Default

CombinationMultiplier
3 × Cherry5×
3 × Lemon5×
3 × Bell10×
3 × Diamond20×
3 × Crown25×
3 × Lucky 750×

Game Flow (Server-side)

USER tekan SPIN │ ▼ SERVER ├── Cek machine status ├── Cek bet (min / max) ├── Cek saldo ├── Lock wallet ├── Generate RNG ├── Tentukan result ├── Hitung payout ├── Update wallet ├── Simpan transaction └── Simpan game session │ ▼ HASIL → CLIENT → ANIMASI REEL → TAMPILKAN
Penting: Browser tidak boleh mengirim result / payout. Browser hanya POST /game/slot/spin. Server yang menentukan semuanya.

Win Probability

Default 10%. Dipakai sebagai parameter RNG — bukan pola tetap “setiap 10 spin pasti menang”. Hasil tetap acak.

Admin Machine Config

  • Status (Active / Inactive)
  • Win Probability
  • Min Bet / Max Bet
  • Payout per simbol (multiplier)

Setiap perubahan konfigurasi dicatat di audit log.

Animasi Reel

Mesin, frame, tombol, background diam. Hanya REEL 1 → REEL 2 → REEL 3 yang bergerak dan berhenti berurutan.

08 — Fitur MVP

Yang Dikunci vs Ditunda

  • ✓ User Wallet + Virtual Coin
  • ✓ Top Up Request + Admin Approve/Reject
  • ✓ Transaction History
  • ✓ 1 Slot Machine (Classic)

  • ✓ Configurable Payout + Min/Max Bet

  • ✕ Cryptocurrency, Mobile App
